核对日期：2026-09-10。对象：本机 PEAK 2.4.b、当前开发版 0.2.1。

## 范围与证据等级

只关注可拾取物品的准星／手持预览，包括食用后产生的毒素、孢子等后果；不扩展为环境荆棘、孢子云或角色附着物的瞄准提示。

本轮未启动游戏、未修改功能或部署 DLL。复核已有真实加载资源日志及当前读取器代码，并读取本机 Assembly-CSharp.dll 的相关 IL。以下“数值一致”不等于真实局内悬停、手持或食用验收通过。

参考：[Food](https://peak.wiki.gg/wiki/Food)、[Cooking](https://peak.wiki.gg/wiki/Cooking)。Food 直接抓取返回 403，使用搜索索引可读取的正文；索引不保证完整，不能宣称已覆盖整页或全游戏食物。

本地证据：`backups/timed-021-evidence/session-45360-20260909T164025637.log`，2026-09-09T16:40:41Z，PID 45360。该日志扫描 194 个加载 Item，其中读取器归类食物 74 个；这不是 74 个唯一食物均验收通过。资源名称存在重复，必须同时记录 item ID。

## 对照变种：毒性与蘑菇特殊效果不能混为一谈

| 资源 | 日志观察 | 能下的结论 |
| --- | --- | --- |
| Bugle Shroom ID 93 | 只有恢复饥饿／食用等动作，无已记录的持续毒素事实（行 70–71） | 与有毒 ID 89 不同；不能按显示名称合并 |
| Button Shroom ID 102 | 无已记录的持续毒素事实（行 159–160） | 与有毒 ID 97 不同 |
| Cluster Shroom ID 88 | 无已记录的持续毒素事实（行 99–100） | 与有毒 ID 84 不同 |
| Chubby Shroom ID 83 | 无已记录的持续毒素事实（行 241–242） | 与 Wiki 列示无毒变种的描述相容；扫描不能证明全游戏不存在其他资源 |

上述观察不是全面“无毒证明”：需要确认完整动作及后续生成效果，并区分实例与默认预制体。当前日志使用 PrefabOnly=true，导致无正向毒素事实的资源仍显示 Unknown；这是保守证据标记，不是毒素值读取失败。

Action_RandomMushroomEffect.RunAction 的 IL 读取本局 MushroomManager 映射或显式 debugEffect，而上述三个有毒蘑菇通过 Action_InflictPoison 提供基础毒性。不能把所有蘑菇毒性都归入本局映射。

## 当前实现遗漏与下一轮验证要求

1. 保留六种已读到的延迟毒素，卡片同时说明总施加量、延迟、时长；不能只显示即时效果。
2. 为 Poison 和 Spores 分别记录证据完整性；其他无关动作未适配，不应自动抹掉已确定的风险事实。
3. 导出每个相关资源的 item ID、内部名、显示名、动作启用状态、触发阶段、statusType/changeAmount、毒素速率／延迟／时长以及烹饪附加行为。
4. 基础资源数值核对、当前实例数据核对、HUD 渲染验证分开记账。真实局内还需覆盖毒／无毒同名变种、烤熟莓果与毒蘑菇、准星／手持切换、移开清除。
5. 本文是部分核对结果，不是全食物支持声明，也不改变当前发布状态。
