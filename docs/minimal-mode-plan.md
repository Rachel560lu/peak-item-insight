# 极简模式计划（待用户 review）

日期：2026-09-12  
基线：0.2.6  
状态：用户已批准实现；开发版 0.2.7 已加入极简视图和测试，发布与局内视觉验收待完成。实现记录见 [minimal-mode-027.md](minimal-mode-027.md)。

后续决定（2026-09-12）：用户局内体验后要求只保留极简版。以下关于双模式和 Detailed 默认值的原始方案已被此决定取代；当前代码只创建极简视图，旧卡片与模式开关已删除。

## 目标与默认选择

根据反馈邮件和用户提供的参考图，新增可选的极简模式：在物品栏上方用原生风格的图标、增减符号和数值显示本次物品效果，减少遮挡和阅读负担。

- 新增 `UI.DisplayMode = Detailed | Minimal`，默认 Detailed，已有玩家升级后保留当前显示方式。
- 两种模式都支持准星与手持，并继续显示原生精力条闪烁预览。
- 沿用当前目标选择：准星优先，无准星物品时回退手持。整套文字与精力条必须指向同一个实例。
- 本次 review 通过后才实施；发布是后续独立步骤。

## 视觉和位置

- 无卡片底色、边框、分类、物品缩略图、长描述、诊断文字；物品名称已有原生 UI 显示，不重复添加。
- 使用游戏原生字体和状态图标。图标用独立 Image，不依赖 emoji 或字体是否支持特殊字符；材质保持独立，避免继承原生淡出或发光状态。
- 一行一个效果，格式为「方向／正负号 + 数值 + 状态图标」，多行紧凑排列并对齐数值。状态颜色与原生 HUD 对应；增减符号明确方向，不能只凭颜色判断好坏。
- 手持：定位在当前选中物品槽原生名称上方。准星：仍放在物品栏上方，并显示一行短名称，明确这是准星物品而非手持物品；不在文字中标注“准星／手持”。
- 实施时先核对库存槽、名称和操作提示的真实 RectTransform，再决定锚点，不能用参考截图像素硬编码。
- 预留与名称、拾取／使用提示的间距，并做屏幕边界限制。空间不足时按行高适度缩小至可读下限，再移动到库存上方可用区域；不静默裁掉危险效果。
- 独立配置 `MinimalScale`、`MinimalOffsetX`、`MinimalOffsetY`，详细卡片的现有配置保持有效。

## 内容规则

极简文字显示物品本次效果的数值；HUD 显示这些效果作用于当前玩家后实际改变的范围。例如食物减 15 饥饿而玩家只有 5 饥饿：文字显示 -15，HUD 只闪烁可恢复的 5。持续效果的累计量和时间必须同时表达。

| 信息 | 极简显示规则 |
| --- | --- |
| 饥饿、伤势、毒素、困倦、石化等 | 本次效果的正负数值 + 对应原生图标；不混成一个净精力数值 |
| 额外精力 | 绿色闪电 + 实际可增加量；受上限限制时与 HUD 使用同一预测值 |
| 清除状态 | 对应状态图标 + 本地化短词“清除”，避免以无限大数值表达 |
| 持续／延迟 | 例如毒素 +10，旁边短注“4 秒 · 延迟 2 秒”；英文随语言切换 |
| 有毒／含孢子 | 即便当前玩家的实际净变化为零，也保留危险图标；有数值行时避免重复。若只确认风险而无数量，显示图标和短词 |
| 未确认毒性／孢子 | 食物相关风险使用图标 + 问号，不能省略后让人误认为无毒；缺少可靠图标时用“毒性？”／“孢子？” |
| 已确认无毒／无孢子 | 省略重复的安全声明，保持界面简洁 |
| 多次使用、耐久、燃料 | 仅显示影响使用决策的紧凑数据，如“3/4 次”；必须确认读到的是次数或耐久，不能把原始字段误当剩余次数 |
| 特殊道具 | 必要时保留短用途，如灵药菇“投掷：范围治疗”；普通岩钉不限休息次数，锈蚀岩钉才会断裂，必须准确区分 |
| 无有效效果或用途的普通物品 | 不画空面板，不输出“部分效果未识别” |

危险状态和作用条件不能为缩短界面而被隐藏。同一状态的即时恢复与延迟增加不能简单相消，数值必须保持各自时序。

参考图中的重量和跑步／攀爬秒数不直接照搬。现有 `ItemPreview` 有 `InfiniteStamina` 标记，但没有专门的活动持续时间字段；资源项也主要是已格式化文字。第一版只显示已经有可靠来源的数值和时间。若无限精力仅有确认的效果类型而无时长，则显示闪电、∞ 和必要短名称；只有核对游戏规则并提供结构化时间数据后，才显示 run/climb 的秒数。

## 技术实施顺序

1. **配置与模式分流**：在 `Plugin.cs` / `PresentationOptions.cs` 增加模式和极简布局配置。在 `RuntimeController` 用同一 `ItemPreview` 选择唯一一个展示视图；切换时清除旧视图，HUD 不依赖简介视图是否有内容。配置项生效时立即刷新，避免目标未变导致仍用旧模式。
2. **结构化行数据**：新增极简行格式化逻辑，读取 `Effects`、风险、额外精力及已核对的资源事实。不能从 `PreviewPanel.FormatBody()` 的富文本或本地化字符串反向提取数字。必要时给资源加类型、数值、单位字段，维持详细模式兼容。
3. **图标与排版**：新增 `MinimalPreviewPanel`，复用游戏字体与原生状态图标，按当前库存及目标名称布局。缺失图标时使用简短本地化名称，不显示缺字方框。只缓存所需引用，在 HUD 重建和切场景后重新绑定。
4. **生命周期**：统一处理目标切换、手持回退、使用中隐藏、暂停、关闭 Mod、场景重建以及模式切换；不改玩家真实状态。
5. **说明与交付**：补充中英 README 的模式切换步骤和极简截图。完成本地验证后提供隔离测试版本，由用户进行视觉验收；验收前不将效果描述为实机通过。

石化错位是已有 HUD 问题，必须单独记录和修复；新增极简文字模式本身不会解决它。它不应被误记为本计划已经完成的功能。

## 验收标准

### 自动化与构建

- 极简行数据覆盖：普通恢复、饥饿减少同时中毒、延迟持续毒性、额外精力上限、清除状态、已知危险但实际增量为零、未知风险、多次使用和无有效行。
- 持续／延迟效果不丢时间，不错误相消；中英文语义一致，不解析本地化字符串取值。
- 同一目标切换模式后只显示一个视图；清理和隐藏不会影响原生 HUD 或留下旧目标信息。
- 运行现有回归检查并构建；新增测试针对数据与行为，不通过重复实现布局算法自证正确。

### 隔离游戏视觉验收

| 场景 | 通过标准 |
| --- | --- |
| 手持食物／准星看另一物品／看地板 | 内容与 HUD 同步切换，不把准星效果误认作手持效果 |
| 有毒食物 | 同时可读饥饿恢复和毒性增加；HUD 保持已有混合效果预览 |
| 零饥饿、毒素已满、额外精力接近上限 | 文字符合上述“物品效果／实际增加”规则，危险不会消失 |
| 岩钉、灵药菇、童军特殊道具 | 保留必要的使用或风险信息，避免空白信息和错误量化 |
| 中文和英文、长物品名、最多效果行 | 不与名称、操作键或库存格重叠，无字体缺字 |
| 16:9、16:10、21:9，常用分辨率与缩放 | 不出屏，字号可读，位置跟随原生 HUD |
| 模式切换、物品切换、暂停、重新进局 | 无残影、重复面板、旧图标或旧数值 |

提交 review 的主要默认选择：详细模式仍为默认；极简模式同时支持手持和准星；手持贴近物品栏，准星在同一区域加短名称；特殊道具允许必要的一行用途；HUD 闪烁独立保留。
