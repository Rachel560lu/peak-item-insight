# 0.2.2 毒食物预览加固与验证

日期：2026-09-10。范围仅限可拾取物品；未发布、未推送。

## 改动

- 保留运行时物品组件中的毒素数值，不按物品名称或 Wiki 表强制覆盖；烹饪后禁用的效果不会因回归清单而重新加入。
- 六种核对值作为独立测试期望：Green Crispberry、Yellow Kingberry、Pink Berrynana，以及有毒 Bugle／Button／Cluster Shroom。按 item ID 区分同名无毒变种。
- 生产预览与加载资源测试共用 StatusProjector。延迟只影响假设食用后的效果时间线，不要求玩家对准毒蘑菇等候 10 秒。
- 新增毒素区域不再继承隐藏模板的空填充；原生状态栏尚无高度时，从健康精力栏读取高度与中心。只修改自有预览图像，不激活原生毒素栏、不修改角色状态。
- 新增 POISON_PULSE 诊断，记录来源、前后毒素、预览区域宽度和闪烁透明度。

这是针对未覆盖原生模板状态的加固；此前截图不足以证明零高度／空填充就是当时唯一根因。

## 下一次局内验收

普通角色，从测试 profile 启动；无需食用即可检查：

1. 对准生绿脆莓：简介有毒，+10 毒素／延迟 2s／持续 4s；未中毒时也应立即开始毒素预览闪烁。
2. 拿在手里看地板：仍显示预览；切换空手并看地板：清除。
3. 对准有毒 Button Shroom：累计 +30／延迟 10s／持续 12s，不必悬停 10s 才显示。
4. 对照无毒同名变种，不能沿用上一个毒蘑菇的紫色区域；现有“未知”证据标签仍不能解读成有毒或无毒。

若卡片有毒而条不显示，查看同一进程的 POISON_PULSE：after>before 确认投影；visible/segments/visibleWidth/opacity 用于区分绑定、几何与相位问题。原相位 opacity=0 是正常闪烁的一部分，不能仅凭单条采样判断失败。
